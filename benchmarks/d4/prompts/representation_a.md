# Blind prompt A — permutation presentation

You are formalizing one presentation of the symmetry group of a square in Lean 4 with Mathlib.

Create one self-contained module named `D4Permutation.lean` in which:

1. vertices are `Fin 4`;
2. a square symmetry is represented extensionally by a permutation of those vertices;
3. rotation sends `x` to `x + 1 (mod 4)` and reflection sends `x` to `-x (mod 4)`;
4. the carrier contains exactly the eight permutations generated by rotation and reflection;
5. multiplication is function composition, and the identity/inverse/closure laws are proved;
6. `W_A` returns the complete induced action on vertices in the fixed order `0,1,2,3`;
7. the module provides an explicit enumeration of all eight elements and proves completeness and
   no duplication.

Do not import a pre-existing dihedral-group implementation as the definition. Do not introduce
`sorry`, `admit`, custom axioms, or an oracle. You are not given, and must not request, another
representation or a cross-representation translator.

Return the exact Lean source plus a machine-readable build report listing the toolchain and all
axioms reported for the principal theorems.
