# Plan: translational truth and basis-independent transformation burden

## Aim

Develop the claim in a falsifiable order: closure is the truth condition for an
admitted relation to continue, before any one language, definition, local/global
perspective, quantity, or entropy measure is privileged.

The plan does **not** assume a universal truth oracle or a universal numerical
cost. It defines exactly what would have to be built and tested before either
claim could be made.

## P0 — vocabulary and evidence hygiene — complete

- Treat translation as a relation, not as a global metalanguage.
- Treat local/global and finite/infinite as inverse readings, not fixed types
  or literal equalities.
- Treat closure as continuation truth, not preservation of a closed truth.
- Preserve historical frozen run artifacts; refactor active interfaces and
  future protocols only.

## P1 — pre-institutional relation interface

Define proof-relevant data before a local language is selected:

```text
R : candidate relation
T : chosen translation witness
rho : independently witnessed return
K : declared constraints and counterexamples
Next : admissible further relation
```

The interface must distinguish `CONTINUES`, `OBSTRUCTED`, and `OPEN`, and must
not use its own verdict as its independent witness. A local language, axiom,
geometry, institution, Turing presentation, or topology then becomes an
explicit representation of this interface.

**Acceptance criterion:** a representation map into the existing `TransFrame`
or `InstitutionFrame` candidate preserves named witnesses and exposes a
counterexample when it does not.

## P2 — transformation-burden object

Define a proof-relevant burden ledger rather than presupposing a scalar cost:

```text
Burden(T, rho) = obligations + exclusions + obstructions + retained residues.
```

Required laws:

1. **Re-expression invariance:** an admitted change of local representation
   carries the same burden relationally.
2. **Sequential composition:** burden for `T2 ∘ T1` is auditable from the two
   legs, including unresolved obligations.
3. **No free self-certification:** a gate cannot erase the burden by issuing
   its own independent outcome.
4. **Residue preservation:** a nonzero route/orientation residue remains in
   the next formation rather than being normalized into identity.

Only after these laws exist may a scalar, order, or resource realization be
proposed—and it must be tested rather than called universal by definition.

## P3 — native controls

Extend the bounded runtime suite with paired controls for:

- the same relation expressed in two local definition bases;
- a composed translation versus its two registered legs;
- independent return versus self-certified admission;
- zero parent residue with distinct children;
- positive finite residues approaching an inverse-limit-style endpoint without
  erasing finite route histories.

**Acceptance criterion:** each positive result retains the exact witnesses;
each failure is classified as obstruction or OPEN, never silently repaired.

## P4 — Lean and Aristotle bridges

1. Formalize the interface and P2 laws in a new Lean module using explicit
   carrier types only as representations, not as metaphysical origins.
2. Prove preservation/reflection and composition theorems, together with at
   least one non-invariance countermodel.
3. Map the admitted Aristotle subinterface into the interface without
   promoting its 34-role evidence to whole-frame equality.
4. Run Phase C2 independently: test whether C1 local return receipts assemble
   into completion over the frozen admitted interface.

The integration requirement is specified in
[Full bounded closure-ASI frontier plan](FULL_BOUNDED_CLOSURE_ASI_FRONTIER_PLAN.md):
the actual C2 result, whether completion, obstruction, or OPEN, must be the
causal source of any successor frame and verifier.

**Boundary:** the Aristotle result can test a specified realization of the
interface. It cannot by itself establish language-prior universal truth.
