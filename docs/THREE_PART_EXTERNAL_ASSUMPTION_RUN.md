# Three-Part External-Assumption Interaction Run

Status: **EXPERIMENTAL RESULT — EXECUTED BOUNDED PROXY**.

This is not an actual ASI or Aristotle run. It is a deterministic finite simulation of three
verification architectures joined into one content-addressed history.

## Parts

1. **Classical full mathematical stack (bounded).** Two isolated D4 learners construct and
   exhaustively execute their local systems. A strong ordinary baseline checks all proposed maps
   and accepts all eight genuine isomorphisms, including orientation reversal.
2. **Closure-native translation.** The same frozen artifacts receive locally assumed equality
   frames, a post-freeze raw candidate, preservation/reflection admission, explicit `(T,phi,pi)`,
   `W/E/J/C` and operation naturality, quotient factors or witnessed openness, and a next basis.
3. **External-assumption interaction.** A registered geometry packet is consumed only after Parts 1
   and 2 freeze. Its frame artifacts freeze before the separately registered candidate packet is
   consumed. Every new equality evaluator receives only its geometry declaration.

The first receipt contains the protocol, total-question, geometry-packet, and candidate-packet
hashes. The nine-link receipt chain records both earlier parts, geometry reveal, external-frame
freeze, candidate reveal, a raw candidate freeze with no verdicts, Part 3, and the final summary.
The packets are scripted repository fixtures and are not supplied as inputs to the Part 1/2
subprocesses; this is causal input separation, not security blinding or independent generation.
Within Part 3 the frame and candidate boundaries are serialized, hashed, receipted, reloaded, and
revalidated by one orchestrator process. A frontier study must strengthen those boundaries with
separate sandboxed producers and verifiers.
