# Closure-native Level-1 genuineness run

This runtime unifies the translating-gate and sorting-cost questions while
preserving their missing premise: a gate cannot establish that it reads a
genuine perspectival receipt merely by accepting it.

```text
receipt reading -> independent Level-1 bridge -> gate audit -> cost receipt
```

The four controls are:

- a calibrated gate audited against an independent signal;
- a structurally specified rubber stamp, detected by false acceptances;
- a missing-bridge case classified `OPEN_NO_LEVEL1_BRIDGE`;
- a self-certification case classified `INVALID_SELF_CERTIFICATION`.

The audit reports false acceptance/rejection, calibration error, evaluated
attempts, refusals, and cost per admitted genuine attempt. The sorting-cost
bound is conditional on the declared cost of evaluating an attempt. The
independent signal is a bounded test fixture, not evidence of real-world
genuineness.
