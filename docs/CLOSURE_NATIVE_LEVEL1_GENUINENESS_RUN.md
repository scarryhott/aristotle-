# Closure-native Level-1 genuineness run

This runtime separates **structural translation** from the truth of the gate's
receipt reading. A gate cannot establish that it reads a genuine perspectival
receipt merely by accepting it.

```text
choice / receipt
  -> structurally translating gate
  -> independent Level-1 bridge
  -> calibration audit
  -> admitted continuation | counterexample | OPEN.
```

The gate is therefore treated as a truth-condition interface on a choice, not
as an entropy-minimization device and not as an oracle that creates truth by
classification.

The four controls are:

- a calibrated gate audited against an independent signal;
- a structurally specified rubber stamp, detected by false acceptances;
- a missing-bridge case classified `OPEN_NO_LEVEL1_BRIDGE`;
- a self-certification case classified `INVALID_SELF_CERTIFICATION`.

The audit reports false acceptance/rejection, calibration error, evaluated
attempts, refusals, and cost per admitted genuine attempt. Those cost fields
belong only to this bounded screening model. They are **not** the universal
transformation cost sought by the foundational thesis, which must be invariant
under language/definition re-expression and attach to relational identity
rather than one gate implementation.

The independent signal is a bounded test fixture, not evidence of real-world
genuineness. Level 1 therefore tests whether admission is related to an
independent natural-choice witness; it does not establish a universal truth
oracle.
