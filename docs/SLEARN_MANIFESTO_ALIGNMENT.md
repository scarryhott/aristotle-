# Slearn manifesto alignment

## Role of the source

The canonical Speed Learn manifesto is maintained verbatim in the Slearn
repository at
[`docs/SLEARN_ORIGINAL_VISION.md`](https://github.com/scarryhott/slearn/blob/agent/derive-slearn-closure-version/docs/SLEARN_ORIGINAL_VISION.md).
It is a design source, not evidence for this repository's Lean theorems or
bounded runtime results. The Slearn claim-level framework is
[`docs/RESEARCH_FRAMEWORK.md`](https://github.com/scarryhott/slearn/blob/agent/derive-slearn-closure-version/docs/RESEARCH_FRAMEWORK.md).

The shared organizing relation is:

```text
Perspective → Why → Goal → Learning → Insight → Action → Experience
            → Return → Perspective′.
```

Here the prime denotes a successor perspective with possible residue and new
questions. It is not literal equality of endpoints, a final worldview, or an
ordinary arithmetic identification such as `0 = ∞`.

## Translation, not compression

The shared research motivation is to reduce avoidable **translation cost**:
the burden of relating a learner or reasoner's present perspective to the
structure that makes an insight intelligible. It is not a claim that knowledge
can be losslessly compressed, that information quantity measures
understanding, or that an intelligence can literally be uploaded in an hour.

The current formal programme can model a chosen translation and test selected
return obligations. It cannot establish a basis-independent cost object until
one has a precise carrier, units, invariance law, and empirical protocol.

## Closure boundary

The research uses “truth-level closure” to name a relation-relative recovery
available through an admitted translation and return. Relative presentations
can remain different in quantity, quality, orientation, route, and residue.
Therefore the mathematical programme must never rewrite a slogan such as
`0–∞`, local/global, or mind/world as literal endpoint equality unless an
ordinary equality theorem actually says so.
