# Reunified next tests: truth translation, chart cocycles, and return

## Purpose

This document unifies the next experiments without changing the evidentiary
meaning of any frozen result.  It adopts the project's corrected criterion:
completion is a warranted **translational truth equality**, not literal
identity of local presentations, a whole-frame reconstruction, a vanishing
trajectory, or an identification of the labels `0` and `infinity`.

The programme has two deliberately separated tracks:

```text
Track 1: frozen Aristotle pair
  B2/C1 -> blind T2A ContactBridge -> frozen bridge -> T2B TruthAssembly

Track 2: independently specified chart--cocycle replication
  local chart forms -> global invariant -> independent return -> residue audit
```

Track 2 must not supply definitions, answers, targets, or a verdict to Track
1.  Its role is a replication of the architecture with a geometrically
explicit question language, not a repair of the Aristotle evidence.

## Shared completion contract

For a pair of presentations `F_A`, `F_B`, a result may report

```text
TruthAssembly = (T, rho, Q, Gamma, Delta)
```

where:

- `T` translates both presentations into the registered relational question
  interface `Q`;
- `rho` is an independently generated return or challenge over `Q`;
- `Gamma` is provenance fixed before any agreement evaluation;
- `Delta` retains rather than erases local differences, non-single-valued
  reopenings, excluded roles, route order, and orientation; and
- truth completion means agreement on the registered answers after translation.

It does **not** mean `F_A = F_B`, `rho (T F_A) = F_A`, structural assembly,
zero residue, or a global `GeomEquiv` claim.

Terminal results are:

- `TRUTH_COMPLETION`: the pre-registered question interface, independent
  return, and independent provenance support agreement;
- `TRUTH_OBSTRUCTION`: an admissible translated question has an explicit
  contradictory answer witness;
- `OPEN_TRUTH_BOUNDARY`: the available evidence cannot warrant comparison;
- `INVALID_LEAKAGE_OR_SELF_CERTIFICATION`: a target, result, or self-issued
  confirmation entered the construction.

## Track 1 -- the frozen Aristotle pair

### T2A: blind ContactBridge generation

T2A remains exactly as submitted.  It reads only the frozen B2/C1 archives
and attempts a minimal object

```text
ContactBridge = (Qcap, embA, embB, rhoCap, GammaCap, DeltaCap).
```

It may generate a bridge, establish a bridge obstruction, or remain open.  It
must not evaluate truth agreement or import later form-depth, ellipse,
topology, physical, B3, C2, or T1 material.

### T2B: blind truth evaluation after T2A freezes

If and only if T2A yields a frozen `BRIDGE_GENERATED` object, T2B compares it
against the separately frozen T1 question record.  T2B must:

1. verify archive and bridge hashes;
2. use T1's question set without changing it;
3. translate answers through `embA` and `embB` into `Qcap`;
4. evaluate each answer with the non-local `rhoCap` and pre-verdict
   `GammaCap`;
5. retain `DeltaCap` and every prior structural obstruction; and
6. emit exactly one terminal classification under the shared contract.

If T2A is `OPEN_BRIDGE_BOUNDARY` or `BRIDGE_OBSTRUCTION`, T2B does not run.
No successor frame, successor verifier, IVI, receipt, topology, or transfer
test may run from an open or obstructed truth result.

## Track 2 -- chart--cocycle replication

This independent replication makes the local/global relation concrete without
turning an optical model into a metaphysical or quantum-gravity conclusion.

### Registered objects before data or verdict

1. **Local charts.** Two presentations of a finite anisotropic/ellipse field
   with named orientation, phase, amplitude, and ordered path data.
2. **Global readout.** A fixed aggregate/invariant map (for example, total
   phase or an explicitly declared interference observable).
3. **Translation square.** Fixed maps satisfying the tested condition

   ```text
   globalReadout o aggregate  ~=  mirrorReadout o T
   ```

   where `~=` names the registered relational equality, not literal equality.
4. **Return.** A separately authored inverse-orientation challenge that does
   not know the expected agreement or desired residue.
5. **Question ladder.** A frozen sequence such as frequency/lift, orientation,
   and ordered provenance.  New questions cannot be added after comparing the
   pair.
6. **Residue.** A record of phase holonomy, orientation mismatch, and route
   order.  A nonzero residue is allowed and is reportable; it is not failure
   by itself.

### Required controls

- same global aggregate but different ordered provenance;
- same frequency but different orientation;
- a coherent rotation that preserves the registered invariant;
- a post-hoc-question attempt, which must be invalid;
- a return authored by the evaluator, which must be invalid; and
- a disagreement on a registered translated question, which is a truth
  obstruction rather than an opportunity to change the chart.

### Evidence boundary

Formal ellipse/phase results can establish facts about the declared finite
model.  Published meta-cavity and polariton experiments can motivate
measurable orientation, phase, coupling, and transport observables.  Neither
establishes that the device detects truth, intent, consciousness, or a general
law of closure.  A laboratory phase would require independently measured
optical data and a preregistered analysis plan.

## Succession gate

Only a `TRUTH_COMPLETION` with all provenance controls passing permits a
separate succession experiment:

```text
completed relation -> published record -> derived frame/verifier
                   -> held-out relation -> independent audit.
```

The derived verifier must not author its own generating relation or select the
held-out question.  This is the point where the bounded verifier-succession
architecture becomes empirically relevant to a frontier-generated relation.
