# Closure-native gate-retention run

This finite control compares four admission rules: reciprocal attempt, central
credential, capital price, and receipt-borne price waiver. Its purpose is to
test which datum decides admission, not to model markets.

- A price gate reads holding only, so it refuses a poor genuine attempt while
  admitting a wealthy non-genuine one.
- The receipt-borne gate admits the genuine attempt despite price; its access
  invariant is therefore carried by the receipt, not by price.
- Under the declared compounding rule, a bounded newcomer remains excluded as
  the top-linked price rises; reciprocal admission continues.
- The twelve fixed paired controls reproduce the registered ordering: price is
  strictly below reciprocal at every row and never exceeds central admission.

No claim is made about real markets, actual chaos, or causal economics. The
runtime is a bounded conditional control aligned with the externally attested
NRRF654 model.
